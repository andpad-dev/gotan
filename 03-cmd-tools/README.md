# 03-cmd-tools の調べ方（逆引き手順）

このカテゴリでは `go` コマンド自体（`go build` / `go generate` / `go vet` など）の挙動を、コマンドのヘルプと `cmd/go` のソースコードから読み解いて課題に取り組みます。
困ったときは、まずここに戻ってきてください。

## サブコマンドが何をするものか知りたい

1. まず `go help <サブコマンド名>`（例: `go help generate`）を実行する。標準ライブラリと同じく、これが一次情報。
2. オンラインで読みたい場合は https://pkg.go.dev/cmd/go を開き、`f` キーで検索してサブコマンド名や見出しにジャンプする。

## コマンドの実装・挙動の根拠を知りたい

- `cmd/go` のソースは https://cs.opensource.google/go/go/+/refs/tags/go1.26.5:src/cmd/go/internal/ 以下にサブコマンドごとのパッケージがある（例: `generate/generate.go`）。
- ヘルプの文言とソースコードの実装は同じリポジトリにあるので、挙動に疑問があれば実装まで読みに行く。

## いつ・なぜ追加された機能か知りたい

- 対象の Go バージョンが分かっている場合、まず `https://go.dev/doc/go1.xx` のリリースノートを見る。
- リリースノートに Issue 番号やプロポーザルへのリンクがあれば、そこから議論の経緯をたどる（`github.com/golang/go` の Issue、`go.googlesource.com/proposal`）。

## 挙動を確かめたい

- 手元で実際にコマンドを実行する。`-n`（実行せず表示のみ）や `-x`（実行したコマンドを表示）のような可視化フラグがあるサブコマンドも多いので、まずヘルプで探す。
