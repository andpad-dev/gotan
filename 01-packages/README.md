# 01-packages の調べ方（逆引き手順）

このカテゴリでは、標準パッケージのドキュメント（pkg.go.dev）を読み解いて課題に取り組みます。
困ったときは、まずここに戻ってきてください。

## 関数・型・メソッドが何か知りたい

1. `https://pkg.go.dev/<パッケージ名>` を開く（例: https://pkg.go.dev/fmt ）。
2. `f` キーを押すと検索ダイアログが出るので、識別子名を打ち込んでジャンプする。
3. まず名前と説明の最初の 1 文で雑に予想を立てる。英語が難しければ翻訳してよい。最初から全部読まない。

## パッケージ全体の使い方・約束事を知りたい

- ページ冒頭の **Overview** を読む。書式や注意点など、個々の関数には書かれていない説明がここに集まっている。

## 使い方の実例が見たい

- **Examples** セクション（`#pkg-examples`）を見る。Example はページ上の Run ボタンでその場で実行できる。

## 挙動を確かめたい

- 手元で `go run` する。手元に環境がなければ Go Playground（ https://go.dev/play/ ）に貼って実行する。

## ドキュメントに書いていないことを知りたい

- 識別子の宣言部分のリンクをクリックすると、実装のソースコードへジャンプできる。
- Go 本体のソースをまとめて読むなら https://cs.opensource.google/go/go を使う。
