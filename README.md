# Go探無比 (gotan) - Go Conference 2026 Workshop

**「Goの探索、豪胆無比に。」**

「Goの `time` フォーマット、毎回覚えられなくてググりがち…」
「この標準ライブラリの関数、errorを返す？それともpanicする？」

Goで開発していると、こうしたシーンに何度もぶつかります。そして、こうした疑問の多くは「一次情報」を正しくたどることで確実な答えにたどり着けます。

本ワークショップは、講師がすべてを解説する一方通行の講義ではありません。参加者自身が手を動かし、一次情報を使って自力で解決する**調査プロセスそのものを体験するグループワークショップ**です。

## 🗺️ 「Go探無比」の由来
**Go探無比** は、「Goの探索」と「豪胆無比」をかけたネーミングです。
かつて開催された、Goの研究や質実剛健をテーマにしたイベント「[質実Go研](https://github.com/goken/goken)」にリスペクトを込め、「わからないことに直面しても、豪胆無比にドキュメントの海を探索し自走できるGopherになろう」という思いが込められています。

---

## 🎯 このワークショップでやること

実際の開発現場で起きる「困りごとシナリオ」にグループ（4名程度）で取り組みます。
以下のような題材を手がかりに、`go.dev` などを入り口として **「どこを・どう見れば解決できるか」** を自分たちの力で探り当てていきます。

* モジュールや `replace` の書き方が思い出せない…
* この標準ライブラリの関数は、errorを返すのか？ panicするのか？
* `reflect` を使うとpanicになるのはなぜか？
* `error` にスタックトレースが付いていないのは、どういう設計判断なのか？

グループでの試行錯誤を通じて、**「Goのドキュメントの歩き方」** を体で覚えましょう！

### 🔍 探索する主なリソース
* `go.dev/doc` / `pkg.go.dev` — Goチームによる公式な一次情報
* `research.swtch.com` — 設計判断の当事者である Russ Cox氏による記事
* `golang.design/history` — 言語の意思決定をたどる手がかり

## 👤 対象となる参加者

* `go.dev` をなんとなく使っているが、使いこなせていない気がする方
* 「なぜGoはこう設計されているのか」を自分で調べられるようになりたい方
* 他のGopherとワイワイ議論しながら学びたい方

## 🎁 持ち帰れるもの

* 「困ったときにどこを・どう見るか」の引き出しと判断軸
* 一次情報を自走して読み解く調査プロセスの体験
* 同じGoを書く仲間が「どこに注目してドキュメントを見ているのか」という新たな視点

## 📂 リポジトリの構成と進め方

このリポジトリは以下のような構成になっています。ワークショップ中は主に `scenarios/` 以下の課題に取り組んでいただきます。

```text
.
├── scenarios/     # 💡 グループワーク用の課題シナリオ（ここを中心に見ます）
│   ├── 01-packages/
│   ├── 02-features/
│   ├── 03-cmd-tools/
│   └── 04-deep-dive/
└── solutions/     # 📖 解説と調査ルート
```

### ワークショップの進め方
1. 4名程度のグループに分かれます。
2. **チュートリアルワーク:** まずは `scenarios/` ディレクトリに用意された基本的な課題にいくつか取り組み、グループメンバーと一緒に公式ドキュメントやソースコードをたどる「調べ方のコツ」を体験します。
3. **テーマ設定:** 調査の感覚を掴んだところで、グループごとに **「今日深く調べたいテーマ」** を設定します。残りのシナリオから興味のある難問を選んでもよいですし、日々の開発で気になっている自分たちの疑問を直接お題として設定しても構いません。
4. **探索ワーク:** 設定したテーマについて深く探索し、答えやその背景を導き出します。なお、本ワークショップでは解説である `solutions/` ディレクトリを最初から公開しています。行き詰まったらヒントとして自由に見に行って構いません。「正解」を知ることよりも、「どのようにしてその情報へ辿り着くか」という調査の過程を体感することを大切にしてください。
5. **全体共有:** 終盤に、それぞれのグループが取り組んだお題について、「どうやって調べたか」「どんな発見があったか」を全体で共有します。
